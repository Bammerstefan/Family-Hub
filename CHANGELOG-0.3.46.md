# BamLabs Family Hub v0.3.46 – Ferienkalender AT/DE

- Optionaler automatischer Schulferien- und Feiertagskalender pro Kind
- Österreich (9 Bundesländer), Deutschland (16 Bundesländer)
- Schulferien und gesetzliche Feiertage einzeln zuschaltbar
- Ferien in Schule/Kita, Kinderwoche, Tagesplan, Packliste und Familienkalender
- Vorhandene manuelle Abwesenheiten und Stundenpläne bleiben erhalten; manuelle Einträge haben Vorrang
- Offline-Cache, Update beim Start und täglich sowie manuelles Neuladen
- Quelle: OpenHolidays API (https://www.openholidaysapi.org/), Daten ODbL
- Schulautonome Tage und Sonderfälle müssen weiterhin manuell überprüft/eingetragen werden
- Frontend, Backend, Manifest und Ladepfad einheitlich v0.3.46
