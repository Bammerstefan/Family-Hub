# BamLabs Family Hub 1.0.0 – erste Release-Version

- Bestehende Funktionen von v0.3.49 übernommen; keine Datenmigration und keine Änderungen an bestehenden Familienprofilen nötig.
- Erweiterte Administrator-Systemprüfung für Tablet-Zuordnung, Ferienkalender, Abwesenheiten, Dienstpläne, Routinen, Listen, Packlisten und Kalender-Zuordnungen.
- Oberfläche, Backend, Ladepfad und JSON-Backup tragen Version 1.0.0.
- JSON-Export bleibt ein Sicherungs-Download ohne automatische Importfunktion. Vollständige Wiederherstellung weiterhin über Home Assistant Backups.
- Die Benachrichtigungszustellung und Verhalten auf verschiedenen Geräten müssen in Home Assistant noch in der Praxis geprüft werden.
